1.  Overview & Purpose
 
The Process Recommendation Module is the central decision engine of PACE. Its role is to accept a characterised feed water dataset and a set of engineering targets, and from those inputs determine the most appropriate membrane process configuration, assess whether the target recovery is achievable without exceeding scaling thresholds, and surface all chemical and operational risks that must be resolved before or after the membrane stage.
 
The module is deterministic — every recommendation can be traced back to an explicit rule and a specific input value. There are no black-box inferences. Each flag produced by the module names the parameter that triggered it and the threshold that was crossed, so the engineer reviewing the output understands exactly why a configuration was chosen and what conditions would change it.
 
This document specifies the complete algorithm: every decision rule, every numerical threshold, the sequence in which checks are applied, the logic for resolving conflicts between competing rules, the structure of the recommendation output, and the integration interface between this module and the rest of PACE.
 
1.1  Scope
This module covers process configuration selection only. Pretreatment selection — coagulation, softening, iron and manganese removal, dechlorination, biological treatment — is handled by the dedicated Pretreatment Module. However, whenever a feed condition makes a specific upstream treatment mandatory before a membrane system can operate, this module raises a pretreatment flag. Certain conditions, such as oil and grease exceeding the direct-membrane threshold or unresolved biological loading in a wastewater feed, cause the module to halt and require the pretreatment question to be resolved first.

3.  Intermediate Computations
Before the seven algorithm phases begin, a set of derived quantities is computed from the raw inputs. These values are used throughout the subsequent phases and are not recalculated at each step unless the recovery ceiling solver adjusts the target recovery during Phase 4.
 
3.1  Concentration Factor and Concentrate Ion Concentrations
The concentration factor quantifies how much the dissolved ion content increases in the reject stream at a given recovery. It is the foundational quantity for all scaling checks.
 
CF  =  1 / (1 − target_recovery / 100)
 
For each dissolved ion in the feed, its estimated concentration in the concentrate stream is:
 
[ion]_concentrate  =  [ion]_feed  ×  CF
 
As a practical example, at 75 % recovery the concentration factor is 4.0, meaning every ion in the concentrate is four times its feed concentration. At 85 % recovery the factor rises to 6.67. These multiplied concentrations are what the scaling checks evaluate — not the feed concentrations.
 
3.2  Estimated Single-Pass Permeate TDS
The algorithm estimates what a single RO or NF pass would deliver as permeate TDS, using standard rejection figures for each membrane class. These estimates determine whether a second pass is necessary.
 
Permeate TDS (BWRO)    =  feed_tds  ×  (1 − 0.980)     →  assumes 98.0 % rejection
Permeate TDS (HP-BWRO) =  feed_tds  ×  (1 − 0.985)     →  assumes 98.5 % rejection
Permeate TDS (SWRO)    =  feed_tds  ×  (1 − 0.995)     →  assumes 99.5 % rejection
Permeate TDS (NF)      =  feed_tds  ×  (1 − 0.600)     →  assumes 60.0 % overall rejection
 
The NF rejection figure is a conservative overall TDS estimate. In practice, NF rejects divalent ions at approximately 95 % while passing 40–70 % of monovalent ions. If the feed is dominated by monovalent sodium chloride, the actual permeate TDS from NF will be considerably higher than the 60 % estimate predicts, which is why the conservative figure is used to avoid false confidence in NF adequacy.
 
3.3  PHREEQC Thermodynamic Engine — Integration
All scaling saturation indices in PACE are computed by PHREEQC version 3 (Lawrence Livermore National Laboratory). PHREEQC replaces manual Ksp-based formulas with a rigorous geochemical treatment that accounts for ionic strength effects on ion activities, temperature-dependent equilibrium constants, and the simultaneous speciation of multiple dissolved phases. Hardcoded Ksp values are not used anywhere in the scaling analysis; all thermodynamic data is drawn from the embedded database.
 
PHREEQC is invoked twice for each project assessment. The first invocation processes the raw feed water composition — pH, temperature, and all measured ion concentrations — to establish the baseline speciation of the feed. This is particularly important for the carbonate system, where the distribution between dissolved CO₂, bicarbonate, and carbonate is strongly pH-dependent and determines how much alkalinity is available to drive carbonate scaling at the membrane surface.
 
The second invocation processes the simulated concentrate. The concentrate composition is prepared by multiplying each measured ion concentration by the concentration factor from Section 3.1. The pH of the concentrate is either taken from measurement if available, or approximated as the feed pH as a conservative bound — in practice the pH at the concentrate face of the membrane can rise slightly due to CO₂ outgassing, which would increase Calcite saturation further, so using feed pH does not understate the risk. PHREEQC processes this concentrate chemistry and returns a saturation index for every mineral phase in the selected database.
 
The thermodynamic database selected is minteq.v4.dat for brackish and low-TDS feeds (TDS below 10,000 mg/L), which uses the Davies equation for activity coefficient estimation. For feeds above 10,000 mg/L — where ionic strength is high enough that the Davies equation becomes less accurate — the llnl.dat database is used, which employs the B-dot extended Debye-Hückel model calibrated at higher ionic strengths. Both databases contain temperature-dependent equilibrium constants, so PHREEQC automatically applies the correct Ksp for the measured feed temperature without any manual correction.
 
The PHREEQC saturation index is defined on a base-10 logarithmic scale as SI = log₁₀(IAP / Ksp), where IAP is the ion activity product computed from the speciated solution. An SI of zero means the solution is exactly at equilibrium with that mineral. Positive SI values indicate supersaturation — the mineral is thermodynamically favoured to precipitate. Negative values indicate undersaturation — the mineral will dissolve if present rather than precipitate. Because the scale is logarithmic, an SI of 0.3 corresponds to approximately twice the equilibrium ion product, and an SI of 1.0 corresponds to ten times. This is a fundamentally more sensitive indicator than a simple concentration comparison because it correctly accounts for both the activity coefficient reduction at high ionic strength and the complexation of ions into neutral pairs such as CaSO₄⁰ and MgHCO₃⁺ that reduce the free-ion activity available for scaling.

4.  Algorithm — Phase by Phase
The algorithm is structured as seven sequential phases. Each phase reads the feed data and the outputs of all prior phases. Phases set flags, adjust derived variables, and write to the recommendation state. Unless a halt condition is encountered, execution always proceeds through all seven phases before an output is produced.
 
4.0  Phase 0 — Data Completeness and Confidence Initialisation
The algorithm begins by verifying that the three mandatory inputs are present. If feed TDS, target permeate TDS, or target recovery is absent, the module halts immediately with a clear error message. No default can substitute for these values because they define the fundamental problem being solved.
 
Once the required fields are confirmed, the algorithm initialises a confidence score of 100 and applies deductions for each absent optional parameter. The score reflects how completely the feed has been characterised and how much uncertainty exists in the recommendation.
 
When pH is absent, the algorithm substitutes a default value of 7.5 and deducts ten points from the confidence score. This default is conservative for many Indian groundwater sources, which can be significantly more alkaline. For feeds with elevated alkalinity, a pH of 7.5 will underestimate the LSI and therefore underestimate carbonate scaling risk. The flag text makes this limitation explicit.
 
When both SDI₁₅ and turbidity are absent, twelve points are deducted, because the UF integration decision — one of the most consequential choices in the algorithm — must rely entirely on source-type heuristics rather than measured fouling potential. When all scaling ions are absent, twenty points are deducted and Phase 4 is skipped entirely, meaning recovery feasibility cannot be confirmed. The output will note that recovery is listed as unverified.
 
A score of 80 or above is classified as HIGH confidence. Scores between 55 and 79 are MEDIUM — the recommendation is directionally sound but should be verified with additional feed characterisation before finalising the design. Scores below 55 are LOW, indicating that critical data gaps exist and the recommendation should be treated as preliminary only.
 
4.1  Phase 1 — Source Type Classification
If the source type has been provided by the user, this phase validates it. If it has not been provided, the algorithm infers it from the available data. Feeds with TDS above 20,000 mg/L are classified as seawater. Feeds between 3,000 and 20,000 mg/L are classified as brackish groundwater. Feeds at or below 3,000 mg/L with turbidity above 2 NTU or TOC above 5 mg/L are classified as surface water, since these quality indicators suggest a surface or mixed source. Feeds at or below 500 mg/L with no significant fouling indicators are classified as low-TDS.
 
Source type classification matters because it governs several downstream decisions. Surface water sources are assigned a worst-case SDI assumption when no measurement has been provided, because the particulate and colloidal loading of rivers and lakes is highly variable and seasonal. Wastewater sources immediately trigger UF integration as mandatory regardless of any measured SDI or turbidity, because the complexity and variability of wastewater chemistry makes it imprudent to design a direct-RO system.
 
For municipal and industrial wastewater sources, the algorithm also checks biological loading. If COD exceeds 150 mg/L or BOD exceeds 20 mg/L, the module halts with a halt message indicating that biological pretreatment must be confirmed in the Pretreatment Module before the membrane configuration can be finalised. Attempting to design a membrane system without resolving high biological loading will produce a configuration that is correct on paper but will fail rapidly in practice.
 
Industrial wastewater with oil and grease above 5 mg/L triggers an unconditional halt, since dissolved and emulsified hydrocarbons at this level will immediately and irreversibly foul both UF and RO membranes. Between 1 and 5 mg/L, the oil and grease risk is manageable with UF integration, which is triggered automatically.
 
4.2  Phase 2 — Fouling Potential Assessment and UF Integration Decision
This phase determines whether ultrafiltration must be incorporated as the first membrane stage. The UF stage serves a specific purpose: to reduce the Silt Density Index of the RO feed to below 2.0, the threshold at which standard spiral-wound RO elements can operate without accelerated particulate fouling.
 
SDI-Based Assessment
When SDI₁₅ has been measured, it is the primary and authoritative input to this decision. A measured SDI₁₅ above 5.0 mandates UF without exception. At this level of colloidal loading, RO membranes would foul within hours of startup. Cleaning intervals would become so frequent that the system could not maintain adequate availability, and the RO elements themselves would suffer premature irreversible fouling.
 
An SDI₁₅ between 3.0 and 5.0 also mandates UF. While some systems have operated direct RO at SDI values in this range with aggressive chemical dosing and frequent cleaning, this is not a design basis that Permionics recommends. The incremental capital cost of a UF stage is almost always justified by the reduction in RO cleaning frequency, extended membrane life, and improved system reliability.
 
For SDI values between 1.0 and 3.0, the decision depends on source type. Groundwater sources in this range may operate adequately with cartridge filtration alone. However, surface water and wastewater sources are never treated as equivalent to groundwater at the same SDI, because surface water SDI varies dramatically with rainfall, season, and upstream events. A design based on a best-case SDI measurement would be undersized for the majority of operating conditions. Therefore, UF is recommended for surface water and wastewater even when measured SDI is in the 1.0–3.0 range.
 
Turbidity Fallback
When SDI₁₅ has not been measured, turbidity is used as a proxy. Turbidity above 1.0 NTU mandates UF. Values between 0.5 and 1.0 NTU generate a strong recommendation for UF. For surface water sources with no SDI or turbidity data, the algorithm defaults to the assumption that UF is required, because it is not possible to design responsibly for an unmeasured fouling parameter with a surface water source type.
 
Organic Loading
TOC above 10 mg/L mandates UF and also raises a biofouling flag for the Pretreatment Module, since at this level biological growth on RO membrane surfaces is a significant operational risk. TOC between 5 and 10 mg/L triggers UF as a recommendation and flags biofouling monitoring as a requirement. At these levels, the combination of UF and a non-fouling RO membrane surface treatment significantly extends cleaning intervals.
 
High colour, above 50 Pt-Co, is an indicator of natural organic matter and humic substances. This triggers UF integration and also notes — for later evaluation in Phase 6 — that nanofiltration may be an appropriate configuration if the TDS target can be met with NF rejection, since NF membranes are particularly effective at humic substance removal.
 
Iron and Manganese
Total iron above 0.3 mg/L triggers both a pretreatment flag (oxidation and filtration is required upstream of the membrane) and UF integration. The UF is included as a safety net after iron removal pretreatment, because iron removal systems have variable performance and any residual colloidal iron reaching the RO membrane would cause rapid, difficult-to-reverse scaling. Manganese above 0.05 mg/L triggers a pretreatment flag but does not independently trigger UF unless other fouling indicators also exceed their thresholds.
 
4.3  Phase 3 — TDS-Based Primary Process Assignment
This phase maps feed TDS to a pressure class and a primary process candidate. It is the coarsest and most broadly applicable filter in the algorithm. The assignments made here are refined and potentially overridden in later phases based on scaling analysis and permeate quality requirements.
 
Ultra-Low TDS: below 200 mg/L
At TDS below 200 mg/L, the feed is already of relatively good quality and the primary objective is typically the removal of divalent ions, hardness, or organics rather than bulk TDS reduction. Full reverse osmosis at this TDS level is energetically disproportionate to the treatment goal. The primary candidate is nanofiltration, operating at 3–6 bar. However, if the application is boiler feed, ultrapure water, or pharmaceutical grade water, the strict permeate TDS requirement overrides the NF assignment and the candidate becomes low-pressure RO.
 
Low TDS: 200 to 500 mg/L
In this range, nanofiltration remains the default candidate for most applications. NF can reliably achieve the softening and divalent removal objectives that are common in this TDS band while consuming significantly less energy than RO. The same application override applies: if the downstream use demands TDS below 50 mg/L — as boiler feed, ultrapure, or pharmaceutical applications typically do — the candidate is upgraded to low-pressure RO.
 
Low Brackish: 500 to 2,000 mg/L
This is the range of most Indian brackish groundwater used for drinking and industrial supply. Single-pass BWRO at 8–15 bar is the standard configuration. The TDS reduction requirement is well within single-pass BWRO capability, and the operating pressure is low enough that energy consumption is manageable without energy recovery devices.
 
Brackish: 2,000 to 5,000 mg/L
Medium-pressure BWRO at 15–20 bar covers this range. This corresponds to a significant portion of Permionics project experience — coastal groundwater, river basins with high natural mineralisation, and industrial reuse feeds. The TDS reduction ratio required here can still be achieved in a single pass with standard 98 % rejection membranes.
 
High Brackish: 5,000 to 10,000 mg/L
High-pressure BWRO at 20–30 bar. At this TDS level, operating pressure increases substantially, and the economic case for energy-efficient high-rejection membranes becomes important. Single-pass operation is still viable for most permeate quality targets at this TDS level, but the Phase 5 permeate TDS check should be confirmed carefully.
 
Very High Brackish: 10,000 to 35,000 mg/L
This range straddles the boundary between high-pressure BWRO and low-pressure SWRO technology. Pressures of 30–55 bar are required. An energy recovery device begins to make economic sense in this pressure range. The algorithm flags this range explicitly because membrane selection — whether to use BWRO elements pushed to their upper pressure limit or low-pressure SWRO elements — is a detailed engineering decision that depends on membrane cost, element pressure rating, and projected energy cost.
 
Seawater: above 35,000 mg/L
SWRO is the only technically viable configuration. Operating pressures of 55–80 bar require high-pressure pumps and, for systems of any meaningful scale, an energy recovery device is strongly recommended. The algorithm flags the ERD recommendation explicitly for seawater assignments. Seawater RO is also the trigger for the most detailed second-pass and boron check in Phase 5, since seawater typically contains 4–6 mg/L boron and product water requirements for desalinated seawater are often stricter than for brackish water.
 
4.4  Phase 4 — Scaling Risk Assessment and Recovery Feasibility
This phase calls the PHREEQC thermodynamic engine with the simulated concentrate composition and reads the returned saturation index for each monitored mineral phase. All SI values are on the log₁₀ scale as defined in Section 3.3. The phase then classifies each mineral into a risk band, raises flags for any mineral at high or critical risk, and — if needed — invokes the recovery ceiling solver. No Ksp values are hardcoded here; PHREEQC owns all thermodynamic data.
 
Calcite — Carbonate Scaling
Calcite SI from PHREEQC replaces the manual Langelier Saturation Index calculation. Because PHREEQC correctly speciates the carbonate system — distributing total alkalinity across CO₂(aq), HCO₃⁻, and CO₃²⁻ based on the actual pH and temperature — its Calcite SI is more accurate than the Langelier approximation, particularly in feeds with elevated pH or high total dissolved solids where the Langelier assumption of ideal activity breaks down. A Calcite SI below zero indicates no carbonate scaling risk. The SI range 0 to 0.5 is low risk where antiscalant is beneficial. Between 0.5 and 1.0 is moderate risk where antiscalant is a firm design requirement. SI above 1.0 is high risk and may require acid dosing in addition to antiscalant to bring the Calcite SI below 0.5 in the concentrate. SI above 1.5 is classified as critical, meaning that the combination of acid and antiscalant alone is unlikely to be reliable at the target recovery, and the recovery ceiling solver is invoked.
 
Gypsum and Anhydrite — Calcium Sulphate
PHREEQC returns separate SI values for Gypsum (CaSO₄·2H₂O) and Anhydrite (CaSO₄). For RO systems operating below 40 °C, Gypsum is the thermodynamically stable form and its SI is the primary check. Anhydrite becomes relevant above approximately 42 °C and is checked for high-temperature applications. An SI above 0 for either phase indicates supersaturation. SI between 0 and 0.3 is moderate risk; antiscalant is strongly recommended. SI above 0.3 is high risk. SI above 0.5 is critical and triggers the recovery solver. CaSO₄ is a particularly insidious scale because it precipitates without warning indicators and is mechanically hard and difficult to dissolve chemically.
 
Barite — Barium Sulphate
Barite warrants the strictest risk thresholds in the algorithm, for two reasons. First, its equilibrium solubility is so low that even microgram-per-litre concentrations of barium in the feed, amplified by a concentration factor of 4 or more, can produce a positive PHREEQC SI. Second, Barite scale once formed on a membrane surface is essentially irreversible by chemical cleaning — the crystal lattice is too stable for the acid and alkali concentrations used in standard CIP protocols. Because PHREEQC accounts for the Ba²⁺ activity coefficient reduction at high ionic strength (which tends to lower the apparent IP relative to a simple concentration-based estimate), the PHREEQC SI is actually a more conservative and reliable indicator than a manual calculation. Any Barite SI above −0.2 is already flagged as moderate risk. SI above 0 — the first point of supersaturation — is high risk and demands a phosphonate antiscalant with documented barium-scale inhibition performance. SI above 0.3 is critical, triggering the recovery solver and an advisory to evaluate barium removal pretreatment, since antiscalant programmes for barium-saturated systems at high concentration factors can be difficult to optimise reliably in the field.
 
Celestite, Fluorite — Strontium Sulphate and Calcium Fluoride
Celestite (SrSO₄) and Fluorite (CaF₂) are assessed with the same PHREEQC SI framework. For Celestite, SI above 0 indicates supersaturation and moderate risk; above 0.3 is high risk; above 0.5 is critical. Fluorite is comparatively rare as a membrane foulant but becomes relevant when feed fluoride is above approximately 2 mg/L. Its SI is evaluated in the same way, with critical classification above 0.5. For Fluorite at high risk or critical, the flag also notes that defluoridation pretreatment or a permeate blending strategy may be more practical than antiscalant dosing, since commercial antiscalant formulations are less universally effective against CaF₂ than against sulphate minerals.
 
SiO₂(a) — Amorphous Silica
PHREEQC computes SI for amorphous silica (phase name SiO₂(a) in the database) alongside the crystalline forms Chalcedony and Quartz. For RO operating conditions, SiO₂(a) is the controlling phase — crystalline silica phases are thermodynamically more stable but kinetically very slow to nucleate at room temperature, so the relevant scaling threshold is amorphous silica solubility. A SiO₂(a) SI above −0.1 is already at the boundary of relevance and is flagged as low risk with a monitoring note. SI above 0 is supersaturation with respect to amorphous silica and is classified as high risk, because silica polymerisation and gel formation can begin almost immediately at supersaturation. SI above 0.2 is critical. Silica scaling is difficult to treat chemically once it has formed and often requires mechanical or high-pH cleaning. A critical SiO₂(a) SI at high target recovery also triggers the HERO configuration hint, as described in Section 4.3.
 
Recovery Ceiling Solver
Whenever any primary mineral phase is classified as critical, the recovery ceiling solver is invoked. It does not recalculate SI manually — instead, it iteratively calls PHREEQC with decreasing recovery values in 5 % decrements, re-preparing the concentrate composition at each step (ions × new CF) and re-running the full PHREEQC speciation. This continues until no primary mineral phase remains at critical risk. The recovery at which this condition is first satisfied is reported as the maximum recommended recovery, and the mineral that was the last to drop out of critical risk is identified as the limiting factor. The solver respects a floor of 30 % recovery — below this, the system would not be economically viable and the engineer must address the scaling chemistry through pretreatment rather than recovery reduction.
 
Secondary mineral phases (Aragonite, Dolomite, Magnesite, Strontianite, Witherite) are evaluated by PHREEQC in the same run but do not trigger the recovery ceiling solver. They are reported in the scaling_risks output object and flagged for the engineer's awareness, because while these phases precipitate more slowly or at higher supersaturation, their presence in a PHREEQC output that already shows primary phases at risk signals a chemically complex concentrate that may behave differently from a simple antiscalant response.
 
When SiO₂(a) SI is critical and the target recovery is above 80 %, the algorithm sets a HERO configuration hint. The HERO process — High Efficiency RO — uses acid dosing to strip carbonate alkalinity in the feed, passes the acidified water through a first RO stage, strips the resulting CO₂ from the permeate, doses caustic to elevate pH and dramatically increase silica solubility in the second-pass feed, and then runs a second RO stage on this alkaline intermediate stream. This sequence breaks the silica concentration ceiling that limits conventional single-pass or two-pass RO, allowing recoveries above 85 % in feeds that would otherwise be constrained to 60–70 %.
 
4.5  Phase 5 — Permeate Quality Assessment and Two-Pass Decision
This phase determines whether the target permeate quality can be achieved with a single RO pass. Several independent conditions can trigger a two-pass requirement, and any one of them is sufficient.
 
TDS Single-Pass Sufficiency
Using the single-pass permeate TDS estimates from Section 3.2 and the appropriate rejection figure for the pressure class determined in Phase 3, the algorithm checks whether the estimated permeate TDS is at or below the target. A 10 % tolerance headroom is included — the system is considered single-pass adequate if the estimated permeate TDS is within 90 % of the target, to account for the reality that membrane rejection decreases over time with fouling and ageing. If the estimate exceeds this threshold, two-pass RO is triggered and the flag states the estimated single-pass value and the target alongside it, so the magnitude of the gap is immediately visible.
 
Application-Based Override
Ultrapure water and pharmaceutical applications mandate two-pass RO regardless of the TDS calculation. These applications have permeate quality requirements — microbial content, endotoxins, conductivity — that go beyond what TDS alone captures, and two-pass RO is a standard industry baseline. For high-pressure boiler feed water with a permeate TDS target below 10 mg/L, two-pass RO is also mandatory, since the conductivity specification for such water typically requires a second RO stage followed by mixed-bed deionisation or EDI.
 
Boron
When feed boron exceeds 1 mg/L and a permeate boron target has been provided, the algorithm checks whether single-pass rejection is sufficient. Standard polyamide RO membranes reject boric acid at approximately 80 % in the neutral pH range (7–8), because boric acid is uncharged at typical feed water pH and is therefore not well rejected by the electrostatic barrier of the membrane. At a target below 0.5 mg/L — the WHO drinking water guideline — two-pass RO is required with caustic dosing before the second pass to raise pH to 9.5–10.5. At this elevated pH, boric acid converts predominantly to the borate anion (H₂BO₃⁻), which the membrane rejects at approximately 97 %. A caustic dosing system becomes a mandatory scope item for such configurations. For targets below 1.0 mg/L, two-pass RO is recommended. Where boron data is absent for seawater sources, the algorithm flags the typical seawater boron range of 4–6 mg/L and recommends confirming the permeate target.
 
Nitrate and Fluoride
When permeate targets for nitrate or fluoride have been provided, the algorithm estimates the single-pass permeate concentration using standard rejection factors — approximately 90 % for nitrate and 96 % for fluoride through BWRO membranes. If the estimated permeate value exceeds the target, two-pass RO is triggered. For fluoride, the flag also notes that dedicated defluoridation media may be an alternative to two-pass RO if fluoride is the only driver and the TDS target can be met with single-pass RO.
 
4.6  Phase 6 — Nanofiltration versus Reverse Osmosis Refinement
This phase is active only when Phase 3 assigned nanofiltration as the primary candidate. Its purpose is to verify that NF can actually satisfy the permeate TDS target and application requirements, and to upgrade to RO where it cannot.
 
The verification begins by checking the NF permeate TDS estimate against the target. Since NF achieves approximately 60 % overall TDS rejection, a feed of 400 mg/L would produce an NF permeate of around 160 mg/L. If the target is, say, 100 mg/L, NF is insufficient and the candidate is upgraded to low-pressure RO. The flag text explicitly states the estimated NF permeate so the engineer can evaluate whether a target relaxation might restore NF suitability.
 
Application requirements also override NF. When the application is boiler feed, ultrapure water, pharmaceutical, or drinking water with a strict TDS target below 50 mg/L, NF is insufficient regardless of the arithmetic estimate, because these applications have product quality requirements beyond simple TDS that NF cannot meet.
 
Where NF is confirmed as appropriate, the algorithm flags the estimated NF permeate TDS and the objective it serves — softening, colour removal, sulfate reduction, or general divalent removal. This makes the recommendation self-documenting: anyone reviewing the output can see not only what was recommended but why NF rather than RO was the correct choice.
 
One important limitation is addressed explicitly: NF cannot be used as a second-pass stage following RO. If a two-pass requirement has been triggered in Phase 5 and the primary candidate is still NF, the algorithm upgrades the candidate to RO, because the purpose of a second pass is to further reduce TDS or remove specific ions from the RO permeate — a task that NF, with its relatively low monovalent rejection, cannot perform.
 
The phase also includes an advisory for feeds in the 2,000–8,000 mg/L TDS range with critical BaSO₄ or high CaSO₄ scaling risk. In such cases, routing the feed through an NF stage before the RO stage can substantially reduce the divalent ion concentration entering the RO, reducing the scaling load and potentially allowing a higher RO recovery. This NF bypass or partial bypass approach is not a standard PACE configuration, but the advisory flag prompts the engineer to discuss it with systems engineering where the scaling chemistry warrants it.
 
4.7  Phase 7 — Final Configuration Assembly
The final phase combines all phase outputs into the single recommendation object that PACE presents to the user. The logic is straightforward: the primary candidate from Phase 3, refined in Phase 6, is combined with the UF integration flag from Phase 2 and the two-pass flag from Phase 5 to determine which of the four configurations is appropriate.
 
When the primary candidate is NF with no two-pass requirement, the final configuration is NF, regardless of whether UF integration was flagged. In such cases, UF is listed as a pretreatment recommendation rather than as a configuration variant, because NF is a standalone process not encompassed by the UF+RO configuration category. The alternate configuration is RO, representing the upgrade path if the TDS target tightens.
 
When the primary candidate is RO, no two-pass, and no UF integration: the final configuration is RO. The alternate is UF+RO, representing the conservative upgrade if a subsequent SDI measurement reveals a fouling risk.
 
When the primary candidate is RO, no two-pass, but UF integration is required: the final configuration is UF+RO. The alternate is RO with enhanced cartridge filtration, representing the option if the SDI measurement proves to be in the borderline range.
 
When the primary candidate is RO, two-pass required, and no UF integration: the final configuration is 2P-RO. The alternate is RO with polishing deionisation, which is relevant where the two-pass driver is a specific trace ion rather than bulk TDS.
 
When the primary candidate is RO, two-pass required, and UF integration is also required: the final configuration is UF+RO, with the second_pass_required flag set to true. The combined UF+2P-RO system is treated as a variant of UF+RO rather than a fifth configuration. The flag text makes the two-pass requirement explicit so the engineer designing the system does not overlook the second stage.
 
The RO variant — distinguishing BWRO at low, medium, or high pressure from HP-BWRO and SWRO — is assigned from the pressure class determined in Phase 3. For two-pass configurations, the variant describes the first stage, since the second stage is always low-pressure BWRO operating on first-stage permeate.
 
Two special configuration variants are set here if the relevant conditions were identified in earlier phases. The HERO hint, set when silica is the critical scaling constraint at high recovery targets, causes the output to recommend the HERO configuration and flag that Systems Engineering should be consulted for detailed process design. The ZLD flag causes the output to note that the RO stage operates to a maximum of approximately 85 % recovery and that a brine concentrator and crystalliser are required downstream.
 
The second_pass_high_ph flag, set when boron removal to a strict target triggered the two-pass requirement, causes the output to explicitly scope a caustic dosing system before the second RO stage. This is a mechanical scope item that must appear in the project specification, and the flag ensures it is not overlooked during detailed design.
